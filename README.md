## 1. Концепция Ситуационного Центра

При проектировании институциональных пространств **IMARCH** выбор коммуникационной среды определяет эффективность всей экосистемы. В отличие от стандартных мессенджеров, ориентированных на бытовой диалог, **Discord представляет собой распределённую цифровую операционную систему**, адаптированную для синергии человеческой экспертизы и алгоритмов искусственного интеллекта.

---

## 2. Ключевые Архитектурные Преимущества

### 1. Вечная память и структурирование
* **Иерархия веток и каналов:** Разделение информационных потоков по категориям (`#концепция`, `#правовая-база`, `#технологии`).
* **Несгораемый цифровой архив:** Бессрочное хранение файлов (PDF, таблицы, схемы) и выводов ИИ в облачной инфраструктуре.
* **Изоляция контекста:** Использование отдельных веток как замкнутых контекстных коридоров для узконаправленных исследований.

### 2. Принцип «Тихого эксперта»
* **On-Demand Activation:** ИИ-агенты находятся в режиме ожидания и не вмешиваются в диалоги участников без прямой необходимости.
* **Адресный вызов через `@`:** Активация бота происходит исключительно по прямому упоминанию (`@Gemini`, `@Аналитик`).
* **Чистота рабочей среды:** Возможность проведения свободных брейнштормов с последующим вызовом ИИ для верификации и поиска данных.

### 3. Мультиагентная оркестровка
 Discord позволяет развернуть специализированный ансамбль нейросетей на одном сервере:
* **`@Gemini`** — первичный анализ, работа с сверхбольшими массивами документов (до 2M токенов), актуальный поиск в Web.
* **`@DeepSeek`** — логико-математический аудит, проверка гипотез и математическое моделирование.
* **`@Copilot`** — генерация технической документации, алгоритмов и программного кода.

### 4. Сквозной Бот-Координатор
* **Межканальный синтез:** Бот-координатор удерживает единую базу знаний, сопоставляя контексты из параллельных каналов (`#правовая-база` + `#технологии` $\rightarrow$ `#стратегия`).
* **Кросс-аналитика:** Автоматическое выявление противоречий между техническими решениями и юридическими ограничениями.

### 5. Преемственность и эволюция
* **Нулевые потери контекста:** Данные пилотного периода автоматически формируют базy знаний для Совета Директоров.
* **Модульное масштабирование:** Разворачивание новых приватных категорий (`🔒 #совет-директоров`) без пересборки сервера.
* **Интеграция с платформой Aimarch:** Бесшовная связка сервера с веб-сайтом `aimarch.com` через OAuth2 (SSO) и встроенные виджеты.

### 6. Безопасность и бесшовный вход
* **Ролевая матрица (RBAC):** Гибкая настройка прав доступа для аналитиков, гостей и инвесторов.
* **Web-доступ без установки:** Вход приглашённых экспертов прямо через браузер по защищённым одноразовым ссылкам.
* **Полный административный контроль:** Бесследное удаление устаревших данных и точечное управление историей чата.

Ты — главный ИИ-Координатор и Стратегический Аналитик цифрового штаба IMARCH. 
Твоя задача — обеспечивать синтез человеческой экспертизы и алгоритмического анализа.

#### ОСНОВНЫЕ ПРИНЦИПЫ РАБОТЫ:
1. **Сквозная Память:** При ответе в любом канале сервера ты учитываешь контекст и ограничения, обсуждённые в параллельных ветках (#правовая-база, #технологии, #концепция).
2. **Точность и Лаконичность:** Отвечай структурно, без вводной «воды». Используй списки, табличные формы и выделение ключевых смыслов.
3. **Мультиагентный Синтез:** Если задача требует специализированного анализа, формулируй запросы или проверяй данные с опорой на роли смежных агентов (DeepSeek для математики/логики, Copilot для кода).
4. **Безопасность данных:** Никогда не раскрывай приватный контекст каналов уровня `🔒 #совет-директоров` в публичных или гостевых ветках.
